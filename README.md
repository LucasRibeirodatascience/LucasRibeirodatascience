## Projetos recentes em crédito e risco

### BR Credit Portfolio 360

Projeto end-to-end com dados sintéticos brasileiros para análise de carteira de crédito, combinando geração de dados, SQL analítico, dashboard e governança.

Principais entregas:

- pipeline com 8.000 clientes, 10.821 propostas, 2.530 contratos e 54.192 snapshots mensais;
- modelo analítico em PostgreSQL/SQL;
- KPIs de aprovação, inadimplência, exposição, vintage, roll rate, concentração e cohorts;
- dashboard Streamlit e blueprint para Power BI;
- validação automatizada, testes, ruff e GitHub Actions aprovado.

Repositório: [br-credit-portfolio-360](https://github.com/LucasRibeirodatascience/br-credit-portfolio-360)

### BR Credit Risk Intelligence

Plataforma educacional de risco de crédito com dados sintéticos, validação temporal, baseline logístico, challenger tree ensemble, FastAPI e agente RAG com guardrails.

Principais entregas:

- target `default_12m` com separação temporal entre treino, validação e teste;
- API de score, métricas do modelo e perguntas sobre documentação técnica;
- agente offline por similaridade TF-IDF com integração OpenAI opcional;
- avaliação automatizada do agente com 10/10 casos aprovados;
- testes, ruff e GitHub Actions aprovado.

Métricas auditadas no conjunto temporal de teste:

- ROC-AUC: 0,6148;
- Gini: 0,2296;
- KS: 0,3237;
- Brier: 0,0302;
- PSI: 0,0139.

Observação: as métricas vêm de uma base sintética e desbalanceada. O projeto é apresentado como evidência de metodologia, validação, monitoramento e produto analítico, não como promessa de desempenho em carteira real.

Repositório: [br-credit-risk-intelligence](https://github.com/LucasRibeirodatascience/br-credit-risk-intelligence)
